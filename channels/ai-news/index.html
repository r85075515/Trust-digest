Thinking Machines 發表 Inkling 2 Mini：26B 模型可跑在 32GB Mac 上

Inkling 2 Mini 是 26.4B 參數的 looped MoE 開源權重模型（Apache 2.0），實際啟用僅 3.4B，checkpoint 約 20GB，可在 32GB Mac 或 DGX Spark 上跑；官方自報 SWE-bench Verified 79.2%，但知識回憶與多輪指令遵循偏弱，分數尚待獨立驗證。

Google Gemini API 預覽 Tool Retrieval：工具 schema 改為按需載入

Gemini API 的 Tool Retrieval 讓 agent 平時只看到工具名稱與短描述，需要時才載入完整參數 schema，解決工具庫一大、每次請求都燒掉數萬 token 的老問題。目前僅 Interactions API 預覽版，Google 尚未公布省 token 的實測數字。

OpenAI 推出 GPT-Live-1.1 語音模型，待機費率降至每分鐘 0.02 美元

GPT-Live-1.1 是全雙工語音模型，主打多語言口音與轉錄更準，並新增 standby 模式：通話閒置時費率從每分鐘 0.05 美元降到 0.02 美元。要注意品質提升全是官方自述、沒有公布任何 benchmark 分數。

來源：MarkTechPost · 11月21日

查證：AI 早報線於 2026-11-22 查證，依據 MarkTechPost 對 OpenAI 開發者文件與模型頁的逐項引用；無 benchmark 一點亦經該文確認

TensorLean 用形式驗證查 GPU kernel，在 FlashAttention 等專案找出 38 個 bug

Columbia 與 CertiK 的 TensorLean 在 PTX 層級形式驗證生產用 GPU kernel：檢查 149 個 kernel 實例、證明 83 個正確，並找出 38 個 bug，其中 23 個在 FlashAttention，還抓到一個跑了 17,760 次測試都沒出現的 data race。

來源：MarkTechPost · 11月22日

Genie 4 進 Gemini API：可即時探索的 720p 互動世界開放給開發者

Google 把世界模型 Genie 4 開放到 Gemini API 與 AI Studio：用文字或圖片就能生成可即時走動、邊玩邊改的 720p/24fps 互動世界，含同步原生音訊。官方也坦言延遲、物理互動與場景持久性仍有限制，現階段比較像原型與 agent 訓練場工具。
