LG 免費開放 K-EXAONE 2.5 API：750B 參數、512K 上下文，OpenAI 相容介面

LG AI Research 11/9 在 NVIDIA AI Day Seoul 宣布，K-EXAONE 2.5 即日起透過 EXAONE API Platform 免費開放，拿 API key 就能用於服務開發與研究。規格為 750B 總參數、31B 啟用，韓英雙語純文字、512K 上下文，端點與 OpenAI 相容。它是 8 月版的後訓練「技術驗證」版而非新一代模型，2.5 本身未開放權重；LG 自測稱 24 項指標綜合進步逾 70%，SWE-Bench Pro 59.21、BrowseComp 78.0 屬廠商數字，且免費期長短與額度都未公布。

來源：Unite.AI · 11月9日

查證：AI 早報線於 2026-11-09 查證，交叉核對 Unite.AI、Spectrum Web、SuperpowerDaily 與 Digital Today（11/9 10:18 KST 發布）對 LG 公告與 EXAONE API 文件的整理，參數、免費開放與相容介面一致；效能數字為 LG 自測，摘要已註明。

開源全雙工語音模型 Sophon-Realtime v1 上線：32B 大腦、Apache 2.0、一張 80GB GPU 可跑

Adventists AI 11/8 在 GitHub、Hugging Face、ModelScope 與 PyPI 釋出 Sophon-Realtime v1，程式碼與權重皆 Apache 2.0 可商用。三個版本共用同一顆由 Qwen3-VL-32B 改裝的 32B「大腦」，能邊聽邊決定輪次、可被打斷；差別只在聲音生成方式：推薦的 Tag 版表現力最強，Flash 版首音延遲僅 0.31 秒、單 GPU 可同時服務 40 人，E2E 版仍是研究預覽、需兩張 80GB GPU。團隊自測 VoiceBench 82.8 與 GPT-4o-mini-Audio 同級，但全是自測數字、尚無第三方評測，且需要一張 80GB GPU 與約 42GB 權重下載。

來源：AICoder · 11月8日

Suno 一週挨兩告：Elvis 權利方祭出 ELVIS 法案、Eminem 出版商為 269 首歌求償約 4,100 萬美元

11/6 兩件獨立訴訟在加州北區聯邦法院提出。Elvis Presley 權利方主張 Suno 未授權複製 859 首作品訓練、並能生成模仿其嗓音的內容，援引田納西州 2024 年 ELVIS 法案；Eminem 的出版商 Eight Mile Style 主張 269 首作品被侵權，按每首法定上限 15 萬美元求償約 4,035 萬、另加版權管理資訊爭議約 67 萬。注意 Eminem 本人不是原告、這些都只是指控尚無判決，Suno 稱已封鎖以藝人姓名下 prompt 的作法；UMG 與 Sony 的舊案仍在進行中，Warner 已於 2025 年和解。

Nvidia 為四款韓國開源模型釋出 Dynamo 部署配方，稱 B200 上推論效能最高 2 倍

Nvidia 11/8 在官方部落格釋出 Dynamo 部署配方，涵蓋 SK Telecom 的 A.X K2、LG 的 K-EXAONE 2.0、Upstage 的 Solar Open 2 與 Motif 的 Motif-3，針對 B200 GPU 優化多 GPU／多機推論，官方稱開箱效能最高可達 2 倍。這是部署設定而非新模型，2 倍為 Nvidia 自家說法；LG 另表示正評估把 Dynamo 用在自家推論維運上，注意配方對應的是 K-EXAONE 2.0，不是同日免費開放 API 的 2.5。

Anthropic 公開 Claude 的 agent 記憶架構：離線「做夢」重寫自己的筆記，自測分數 13% 跳到 48%

Anthropic 11/6 發表工程長文拆解 Claude agent 如何跨 session 記憶：保存對話紀錄、由模型自己寫筆記、連結成知識結構，每次 session 開頭只載入一小塊上下文；更特別的是離線「做夢」機制，會回看過去紀錄、修正自己寫錯的筆記。Anthropic 自測稱，做夢讓一組 25 題測驗的達標率從 13% 升到 48%，記憶功能也讓 Opus 5.5 在一項資料庫任務的平均獎勵從 0.655 升到 0.838。方向值得注意，但數字全是原廠自測、無外部複現。

來源：TechSambad (linking Anthropic original) · 11月6日

查證：AI 早報線於 2026-11-09 查證，交叉核對 TechSambad 11/8 彙整（附 Anthropic 原文連結）、ThorstenMeyerAI 11/8 實驗室週報與 FourWeekMBA 的科學週報，記憶組成、做夢機制與兩組自測數字一致；原文發布日為 11/6、週末獲深度報導，摘要已註明日期。

提醒：Cursor 的 OpenAI 模型存取 11/12 到期，本週內要換預設模型

OpenAI 8/28 已宣布將停止供應模型給 Cursor，截止日就是本週四 11/12，11/8 起倒數報導陸續出現。若你的 Cursor 預設還掛著 OpenAI 模型，到期當天會直接斷供，建議本週先改成 Claude、Gemini 或 Grok 並跑一輪日常任務確認無礙。影響面據報導不大——Cursor 執行長稱 OpenAI 模型僅占其總用量約 5%，但該數字未經獨立稽核，個別重度使用者的工作流仍可能中招。
