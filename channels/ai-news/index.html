PSI 稱 AI 三天證明懸置 18 年的 Aaronson-Ambainis 量子猜想，Lean 已驗證、但尚無同儕審查

開發工具同日更新：Claude Code 2.1.319 把 MCP 任務放背景跑，Google ADK 2.14 把 A2A 協定轉正式版

兩款開發工具都在 11/7 發版：Claude Code 2.1.319 讓 MCP 工具以任務方式呼叫時直接轉到背景執行、完成再通知，不必卡著等它跑完，並新增 denyInsteadOfPrompting 設定、調整 /loop 行為。Google ADK 2.14.0 則把 agent 對 agent 通訊的 A2A 協定、執行環境與核心 runtime 一起標為 stable，代表介面承諾穩定、不再隨便改；有一處不相容變更（部分工具設定改為固定型別）。A2A 轉正的長期意義最大：不同廠商的 agent 之間開始有穩定可依賴的互通規格。

Grok API 文字浮水印 11/7 起預設開啟：七款模型全中，關閉要管理員宣示法律例外

SpaceXAI（原 xAI）11/7 起按先前公告，把 Grok API 的隱形文字浮水印設為預設開啟，涵蓋 grok-4.7、4.6、4.5、4.3 與三款 grok-4.20，Responses 與 Chat Completions 都算，連結構化輸出與工具呼叫參數也被標記，回應會多一個 x-watermark 標頭。官方理由是配合歐盟 AI Act 第 50 條。要關閉只能由團隊管理員逐模型操作，且須確認「有法律例外適用」並自負標示義務、變更會被記錄。此變更只及 API，grok.com 與 X 上的消費版不在此 docs 範圍內。

四大廠共同支持統一的 AI 訓練退出訊號：robots.txt 一個 token 管全部，2027 年陸續生效

Google、Microsoft、OpenAI 與 Anthropic 共同表態支持 IETF 的 AIPREF 草案：在 robots.txt 加上 __usage_ai-training 這個 token，網站就能一次對所有廠商表達「不要拿我的內容訓練模型」，可套全站或指定路徑，而且與「可否被 AI 回答引用」（grounding）分開決定。時程上 Microsoft 明言 2027/2/1 起 honoring 訓練退出、Google 規劃 2027 年內上線（未另設 Google-Extended 時視同退出），OpenAI 承諾跟隨、Anthropic 稱爬蟲支援開發中。注意這仍是草案，語法可能變，現在不必急著改 robots.txt，先想好自家政策即可。
