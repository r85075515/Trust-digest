OpenAI：GPT-6 只靠推理與寫程式設計蛋白質，實驗室驗證 35/322 命中

OpenAI 11/24 發表 preprint：GPT-6 家族不用專門生醫模型、只靠推理與程式設計蛋白質結構與序列；夥伴 Onava 在實驗室合成 322 個 minibinder，35 個（10.9%）對全部 5 個靶點出現結合證據。但候選篩選仍靠專門模型、結構預測明顯落後，且尚未同行審查——是證明通用模型能跨進生醫設計的訊號，不是藥物突破。

Claude artifacts 可一鍵裝成 Mac/Windows 桌面 app（beta）

Anthropic 11/24 推出 Install as app beta：在 Claude 裡用一句話做出的 artifact，可直接裝成有獨立圖示與視窗的桌面 app，免打包、簽名與 API key，全方案可用。三級權限中最高級可跑程式、讀改刪本機檔案，且 Anthropic 明言不預審這些 app——方便，但只裝自己或可信來源做的。

MCP 兩週年：Anthropic 推 Skills over MCP 公測、Tasks 與 Elicitation 轉 GA

Anthropic 11/24 在 MCP 兩週年宣布：MCP 伺服器可隨工具附上「技能說明書」（Skills over MCP，公測），讓 Claude 照最佳實務做多步驟工作；長時間任務可丟背景跑的 Tasks 與中途向使用者確認的 Elicitation 轉正式版。MCP SDK 月下載量已逾 7 億次，agent 的「工具＋說明書」正成為標準配備。

Google Workspace MCP 與 CLI 轉 GA，2027 年 2 月起 agent 強制走 MCP

Google 11/24 宣布 Workspace MCP servers（涵蓋 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat、Tasks）與官方 CLI 正式上線，agent 可用受治理的標準介面存取 Workspace。同時立下期限：2027-02-01 起 AI agent 不得再直打 REST API、必須走 MCP；高用量 Scaled tier 2027-04-01 起計費（價格未公布）。有在做 Workspace agent 的團隊要排遷移了。
