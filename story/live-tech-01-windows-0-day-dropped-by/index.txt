10:T5b2,Lede: A researcher who has been publicly feuding with Microsoft has disclosed yet another Windows zero-day, this time a flaw that hands local users full System rights on some versions of Windows.

What happened
Nightmare Eclipse, the pseudonym of a researcher with an ongoing, very public dispute with Microsoft, disclosed SignDrop on Tuesday. The vulnerability gives local users full System rights on some versions of Windows, according to Ars Technica. It resides in the Common Log File System, which Microsoft describes as a general-purpose logging service.

Why it matters
A local privilege-escalation flaw matters because any user who can run code on an affected machine could gain the highest level of system access, turning a minor foothold into full control. The public disclosure also continues a pattern of confrontation between the researcher and Microsoft, raising the stakes for users waiting on a patch.
